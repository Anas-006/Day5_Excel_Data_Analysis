Task 5 – Excel Data Analysis

Project Overview

Analyzed the Sample Superstore dataset using Microsoft Excel to understand sales, profit, orders, categories, regions, and monthly sales trends.

Tools Used

- Microsoft Excel
- PivotTables
- Excel formulas

Analysis Performed

- Calculated Total Sales, Total Profit, and Total Orders
- Used SUMIFS for category and region analysis
- Created PivotTables for:
  - Sales by Category
  - Sales by Region
  - Sales Trend by Month
  - Sales by Segment
  - Profit by Category
- Created a Summary sheet with key KPIs and findings

Key Findings

The analysis identifies the highest-performing sales categories and regions and shows monthly sales trends. Profit analysis also helps identify the most profitable category and supports better business decision-making.

Rollback Evidence

Created version 1 of the workbook before making a small update. After the update, version 2 was saved. Version 1 can be restored if the latest change causes an issue.

Outcome

This project improved practical skills in Excel data analysis, formulas, PivotTables, KPI reporting, and business insights.
